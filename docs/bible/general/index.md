# Les règles générales

Ce qui vaut **partout**, quel que soit l'organe et quel que soit l'écran. Une règle qui ne vaut
que pour une famille d'organes n'est pas ici : elle vit sous sa catégorie.

| Page | Ce qu'elle porte |
|---|---|
| **[Le panneau](panneau.md)** | l'écran de référence, le `blg`, le zoom |
| **[Les cadres](cadres.md)** | `F`/`FF`/`FS`, carte/dalle/tuile, les voiles |
| **[Le budget](budget.md)** | qui porte sa cote, qui la déduit |
| **[Les listes](listes.md)** | la page de quinze, la pagination |
| **[L'écriture](ecriture.md)** | `T1`–`T7`, les liens, la mise en mots |
| **[Les gestes](gestes.md)** | ce qui défile, les cibles du doigt |
| **[Le socle](socle.md)** | ce que vaut une norme, `socle.mjs`, le rendu |
