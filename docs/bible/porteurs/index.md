# Les porteurs

Un porteur **contient** : le jeton porte un nom, le collecteur reçoit un jeton, la saisie reçoit
du texte. Le jeton et son collecteur sont la paire centrale du builder — même cote, même
écriture, lues sur un seul jeton de mesure. Aucune règle d'emplacement ne leur est commune.

| Objet | Ce que c'est |
|---|---|
| **[Le jeton](jeton.md)** | ce qu'on glisse — `87 × 48` |
| **[Le collecteur](collecteur.md)** | ce qui le reçoit — même cote |
| **[La saisie](saisie.md)** | la zone d'écriture |
