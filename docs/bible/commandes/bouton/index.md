# Le bouton

Le bouton est la commande à libellé : un octogone à coupe, opaque, en trois gabarits, qui porte
l'échelle des quatre couleurs. C'est l'organe le plus normé du builder — `37` règles, servies
en trois pages sœurs.

| Rubrique | Ce qu'elle porte |
|---|---|
| **[Design](design.md)** | l'octogone, l'opacité, les quatre couleurs |
| **[Mesures](mesures.md)** | les gabarits, les largeurs, la hauteur |
| **[Fonctions](fonctions.md)** | les verbes, les portes, le verrou |
