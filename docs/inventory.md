# Party Inventory

The **shared loot ledger** of your campaign: everything the party hauls out of dungeons lands here. It separates **Raw ingredients**, **Forgable parts**, and **Other equipment**. Craft Structures into bodies, infuse Essences into Soulgems, identify Catalysts, then send prepared parts to the **Soulforge**.

Everyone at the table sees the same list — it lives on the campaign server, keyed by your **campaign code**.

If this browser still contains an inventory from the former local Soulforge Workshop, a one-time **Import old Soulforge inventory** button appears after the campaign loads. The browser copy is removed only after the complete server import succeeds.
