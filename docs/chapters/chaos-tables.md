# Tables de Fatalité par Attribut

**Règle :** Lorsque le personnage subit une conséquence basée sur un attribut (FOR, DEX, CON, SAG, INT, CHA), lancez 1d6 + niveau de dépassement. Comparez le total au tableau (1 à 12). Un score élevé est plus grave. Au plus haut niveau, l’effet est potentiellement fatal. Les durées et effets sont indicatifs, le MJ peut ajuster selon la situation. Des soins magiques ou un repos prolongé peuvent être nécessaires pour annuler les effets les plus sévères.

---

## Force (FOR)

| Résultat | Conséquence                                                                                   |
| -------- | --------------------------------------------------------------------------------------------- |
| 1        | Contracture légère : -1 aux tests de FOR pendant 1 heure.                                     |
| 2        | Entorse mineure : douleurs vives, -1 aux tests de FOR jusqu’au prochain repos long.           |
| 3        | Crampes récurrentes : -2 aux tests de FOR pendant 24h.                                        |
| 4        | Déchirure musculaire superficielle : -2 en FOR pendant 24h.                                   |
| 5        | Foulure d’un membre : demi-vitesse si jambe, désavantage sur les tests de FOR si bras.        |
| 6        | Microdéchirures : -2 en FOR jusqu’au prochain repos long.                                     |
| 7        | Déchirure musculaire profonde : -4 en FOR pendant 1d4 jours.                                  |
| 8        | Tendon fragilisé : désavantage sur tous les jets de FOR ou attaques au CàC pendant 1 semaine. |
| 9        | Fracture osseuse : impossible d’utiliser le membre, -4 en FOR jusqu’à guérison.               |
| 10       | Rupture musculaire critique : -1 permanent en FOR (sauf soins rares).                         |
| 11       | Invalidité majeure : -6 en FOR pendant 1 mois, nécessite des soins avancés.                   |
| 12       | Rupture totale (fatal) : Mort ou perte permanente d’usage d’un membre vital (au choix du MJ). |

| 8 | Nerfs endommagés : désavantage permanent en DEX jusqu’à guérison, vitesse réduite. |
| 9 | Dislocation sévère : impossible actions fines (crocheter, escalader) sans soins. |
| 10 | Lésions tendineuses : -1 permanent en DEX. |
| 11 | Mutilation mineure (doigt/orteil) : -2 permanent en DEX. |
| 12 | Paralysie d’un membre (fatal) : incapacité de déplacement normal, potentiellement mortel. |
