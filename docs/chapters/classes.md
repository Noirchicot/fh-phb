# Classes — Fate's Hand modifications

- **Rogue** — gains **Sneak Critical** at level 2: **+1 critical range**.
- **Fighter**, **Ranger**, **Paladin** — see **Great Weapon Fighting** (`5. Feats/Feats.md`).
- **Monk** — **Deflect**: *(unarmed dice + Monk level + DEX)*; if this covers all the damage, that damage is reflected.
- **Assassin** (**Rogue**) — gains the **Garrot** free at level 3 (otherwise bought from the skill pool for **2 points**). See Battlefield Rules.
