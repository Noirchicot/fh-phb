# IV. The Emperor

![The Emperor — Fate's Hand tarot](../../assets/img/tarot/major/IV.jpg){ .fh-card-illus }

- **Meaning** — authority, order, stable power. Construction, organization, protection.
- **Signature Ability** — Charisma
- **Destiny Impact** — +1
- **Power** — once per long rest, sacrifice a die to obtain the highest possible bonus non-critical result.

### Vibrations of The Emperor { .fh-clear }

| Rank (vp) | Vibration | Effect |
| --- | --- | --- |
| 1 | **Sovereign Bearing** | advantage on one saving throw |
| 2 | **Imperial Aegis** | *Shield of Faith* |
| 3 | **Bond of the Crown** | *Warding Bond* |
| 4 | **Imperial Writ** | *Dispel Magic* |
| 5 | **Throne's Bulwark** | 1 h: resistance to bludgeoning, piercing and slashing |
| 6 | **The Unshaken Throne** | when you or an ally within 30 ft fails a saving throw, it succeeds instead |
